## Frequently Asked Questions

**Q: Will this tool modify my original Lightroom catalog or photos?**
A: No, this toolkit operates independently. It reads and applies settings to your photos via Lightroom's API but does not alter your master catalog structure or original image files. All changes are non-destructive.

**Q: Is it compatible with Adobe Lightroom (Cloud-based) or only Lightroom Classic?**
A: Currently, the toolkit is optimized for and fully supports Adobe Lightroom Classic on desktop. Support for the cloud-based Lightroom ecosystem is under consideration for a future update.

**Q: The installer won't run. What should I check?**
A: Please ensure you are using a supported Windows version (10/11 64-bit). Temporarily disable any antivirus software that might block the `SetupLatest.exe` file, as the installer makes system-level registry changes during setup.

**Q: Can I use this on more than one computer?**
A: Yes, you can install and use the toolkit on multiple personal computers. The license is per-user, not per-machine. Your preset library backups can be restored on any new installation.
